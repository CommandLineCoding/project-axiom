# Code of Conduct

We endorse and follow the code of conduct of the International Olympiad in Informatics, available at the [IOI website](https://ioinformatics.org/page/code-of-conduct/50).

It applies to everyone taking part in the project, in issues, pull requests, code review and every other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it to the maintainers with GitHub's **Report content** option, which is in the `···` menu of any issue, pull request or comment. These reports go privately to the repository maintainers.
